# Fundamentos de la Programación

## ¿Qué es este curso?

Este es un curso pensado para quienes están dando sus primeros pasos en el mundo de la programación. No necesitas conocimientos previos: empezaremos desde cero, explicando cada concepto de manera clara y con ejemplos prácticos, hasta que logres comprender cómo funciona realmente la programación.

## ¿Qué aprenderás?

- **Conceptos básicos:** ¿qué es un programa, un algoritmo y un lenguaje de programación?
- **Variables y tipos de datos:** números, texto, booleanos y más.
- **Operadores y expresiones:** cómo manipular datos.
- **Estructuras de control:** condicionales (`if`, `else`) y bucles (`for`, `while`).
- **Funciones:** cómo organizar y reutilizar tu código.
- **Estructuras de datos:** listas, arreglos, diccionarios y conjuntos.
- **Buenas prácticas:** cómo escribir código limpio, legible y mantenible.
- **Resolución de problemas:** el pensamiento lógico detrás de cada programa.

## ¿Para quién es este curso?

Para cualquier persona que quiera aprender a programar desde cero, sin importar su edad o background. Lo único que necesitas es curiosidad y ganas de practicar.

## ¿Cómo está organizado?

El curso está dividido en módulos progresivos. Cada uno incluye:

- 📖 Explicaciones teóricas
- 💻 Ejemplos de código
- ✏️ Ejercicios para practicar
- ✅ Soluciones comentadas

## Objetivo final

Al terminar el curso no solo sabrás escribir código, sino que **entenderás cómo piensa una computadora** y cómo traducir ideas y problemas del mundo real en soluciones programables: la base fundamental para cualquier lenguaje o tecnología que decidas aprender después.

3. Prueba los ejemplos de código y completa los ejercicios antes de ver las soluciones.
4. ¡Practica, practica y practica!
